# Security Policy

## Supported Versions

Security fixes are released for the latest version of Robocode.

## Reporting a Vulnerability

Please report security vulnerabilities privately, so they can be fixed before they are made
public. Do not open a public issue for a vulnerability.

Report it through the repository's **Security** tab
(https://github.com/robo-code/robocode/security), using "Report a vulnerability" if it is
available. We will confirm the report, work on a fix, and credit you in the security advisory
unless you prefer otherwise.
